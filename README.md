# أداة توليد وتخصيص أوراق الأبحاث (ICaTAS 2026 Paper Generator)

تم تطوير هذه الصفحة لتلبية طلبك بدقة متناهية باستخدام **HTML5, CSS3, JavaScript** النقي (Client-Side بالكامل بدون الحاجة لخادم backend).

---

### ✨ المميزات الرئيسية:
1. **كتابة الاسم و ID**:
   - حقول إدخال واضحة للاسم الكامل ورقم الـ ID (باللغة العربية أو الإنجليزية).
   - تحديث مباشر وفوري في ورقة البحث (Live Real-Time Preview) أثناء الكتابة.

2. **توليد ملفات بألوان مختلفة لمنع التشابه**:
   - زر كبير ومميز: **"توليد ملف جديد (ألوان عشوائية جديدة)" 🎲** يقوم بإنشاء لوحة ألوان توافقية جديدة تماماً في كل ضغطة.
   - تضمين 10 باليتات ألوان أكاديمية مختارة بعناية (أزرق ملكي، زمردي، عنابي أكسفورد، بنفسجي إمبريالي، نحاسي، تيتانيوم رمادي، فيروزي، وغيرها).
   - إمكانية التعديل اليدوي على كل لون بدقة عبر Color Pickers.
   - خيار إضافي لتوليد تواريخ واقعية عشوائية للمقال (Received, Revised, Accepted, Published) لمنع تطابق الملفات بين الطلاب.

3. **مطابقة تامة لملف الأصل (assignment.docx)**:
   - ترويسة المؤتمر (ICaTAS 2026).
   - عنوان البحث وموضع الاسم والـ ID.
   - بيانات الكلية (Arab Academy for Science Technology and Maritime Transport).
   - جدول المستخلص والكلمات المفتاحية والمصطلحات الملونة (Highlights).
   - قسم المقدمة (1. INTRODUCTION) مع الصورة الهندسية لمسار الدرون والرادار (Image 1).
   - قسم نموذج الرصد (3.1 ISAR-TBD Observation Model) مع المعادلات الرياضية (1) و (2) وجدول المعاملات (Image 2).
   - المخطط الانسيابي الكامل للخوارزمية المقترحة (Image 3).

4. **خيارات التصدير والتحميل**:
   - **تحميل كملف Word أصلي (DOCX)**: يقوم بتوليد ملف `.docx` حقيقي 100% يحتوي على اسمك والـ ID الخاص بك والألوان التي اخترتها أو ولدتها عشوائياً.
   - **طباعة / حفظ كـ PDF عالي الدقة**: يفتح نافذة الطباعة المخصصة لورق A4 بدقة متناهية وبدون أي أزرار أو حواف غير مرغوبة.
   - **تحميل صفحة ويب HTML مستقلة**: ملف HTML مدمج به كافة الصور والتنسيقات ليعمل في أي مكان بدون إنترنت.

---

### 🚀 طريقة الاستخدام:
- قم بفتح ملف `index.html` بالنقر المزدوج عليه في أي متصفح (Google Chrome، Microsoft Edge، Firefox).
- اكتب اسمك ورقم الـ ID.
- اضغط على **"توليد ألوان جديدة عشوائياً"** للحصول على شكل فريد وجديد.
- اضغط على **"تحميل ملف Word (DOCX)"** أو **"طباعة / حفظ كـ PDF"**.
